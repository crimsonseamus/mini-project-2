# 🍽️ Restaurant Website

A simple and responsive restaurant website built using **HTML and Tailwind CSS** as part of Mini Project 2 for Software Development I.

## 🌐 Live Demo

[View Website](https://d3mo-restaurant.netlify.app/)

## ✨ Features

- Responsive design for mobile and desktop.
- Simple navigation bar.
- Home, Menu, and About sections.
- Food menu with prices.
- Hover effects and interactive navigation.
- Clean and minimal UI.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

*Note: An internet connection is required to load Tailwind CSS from its CDN.*
